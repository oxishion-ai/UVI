Le langage

Une syntaxe courte, un moteur qui ne triche pas

Chaque symbole d'UVI a un seul sens, appris en une phrase. Deux moteurs d'exécution — un interpréteur qui lit l'arbre de syntaxe directement, une machine virtuelle qui compile en bytecode — tournent en parallèle sur la même suite de tests pour garantir qu'ils rendent toujours le même résultat.

! "Bonjour, UVI !" % 3 -> ! "Itération"
Sortie
Bonjour, UVI ! Itération Itération Itération

% répète un bloc N fois — pas de parenthèses, pas de deux-points, une flèche.

DEF carre(n) -> _retour = n * n CALL carre(7) -> resultat ~ resultat > 40 -> ! "Grand carré" || ! "Petit carré"
Sortie
Grand carré

Une fonction, un appel avec destination, un IF/ELSE en une ligne (~ ... -> ... || ...).

TAB scores TAB.PUSH scores -> 92 TAB.PUSH scores -> 78 TAB.LEN scores -> n ! n
Sortie
2

Tableaux dynamiques intégrés au langage, pas une bibliothèque à importer.

i = 0 %% i < 100 -> ~ i == 5 -> @STOP || ! i | i = i + 1
Sortie
0 1 2 3 4

@STOP arrête tout le programme immédiatement, depuis n'importe quel niveau d'imbrication.

⚙

Deux moteurs, un seul résultat

Interpréteur d'arbre ET machine virtuelle bytecode, vérifiés l'un contre l'autre par une suite de tests dédiée — un écart entre les deux est traité comme un bug, jamais toléré.

◆

Bac à sable réel

Le stockage de fichiers d'un script est confiné par construction — aucun chemin ne peut s'échapper vers le reste du disque, même volontairement.

↻

S'auto-corrige

Un script qui plante peut être diagnostiqué et réparé par l'assistant intégré ; !LEARN permet aussi d'enseigner une correction directement depuis le terminal.

▦

Dessine, joue, écoute le clavier

DRAW.* pour un canevas graphique, KEY.* pour lire le clavier en direct — de quoi prototyper un petit jeu sans quitter le langage.

▤

Modulaire

MODULE/EXPORT pour des espaces de noms isolés, IMPORT pour de l'inclusion directe, un registre de paquets pour partager du code UVI.

L'assistant intégré

Shion lit ton code, pas une supposition

Quand on te demande d'expliquer, d'optimiser ou de déboguer un script, Shion ne devine pas la syntaxe par analogie avec Python — l'IDE lui donne la vraie grammaire d'UVI et l'arbre de syntaxe réel produit par le compilateur. Et tout peut tourner en local : Shion est une petite famille de modèles maison, entraînés et exécutés sans dépendre d'un service externe.

  • Zéro-dépendance pas de framework de deep learning — juste NumPy et des maths écrites à la main, vérifiées par différences finies
  • Tokenizer octet aucun vocabulaire à télécharger, n'importe quel texte UTF-8 fonctionne dès le premier octet
  • Mémoire bornée les couches sont chargées et déchargées à la demande — la RAM utilisée ne dépend jamais de la longueur de la conversation
  • Sur mobile aussi Shion Mobile fait tourner DeepSeek-R1-Distill-Qwen-1.5B directement dans le navigateur du téléphone via WebGPU, sans serveur

Où UVI excelle

Un même langage, plusieurs terrains

Apprentissage

Une grammaire volontairement petite (une poignée de symboles, pas de mots-clés à mémoriser par dizaines) et un assistant qui explique chaque ligne avec le vrai arbre de syntaxe sous les yeux.

Prototypage de jeux

DRAW.* et KEY.* intégrés au langage — un canevas, des sprites, une boucle de jeu, sans bibliothèque externe à installer.

Scripts & automatisation

Tableaux, chaînes, fichiers, tout ce qu'il faut pour un petit outil du quotidien — avec des limites de ressources qui empêchent une boucle infinie de figer la machine.

Recherche sur les petits modèles locaux

Shion est un pipeline complet — tokenizer, attention, quantification, service HTTP — écrit pour être lu et modifié, pas juste appelé comme boîte noire.

Accessibilité linguistique

Interface en anglais, français, espagnol, mandarin ou hindi ; le langage lui-même reste identique partout, seule l'habillage change.
