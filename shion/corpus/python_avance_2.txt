Q: Qu'est-ce qu'un decorateur en Python ?
R: Un decorateur est une fonction qui prend une autre fonction en argument et retourne une fonction modifiee, souvent via la syntaxe @nom_decorateur.

Q: Comment ecrire un decorateur simple ?
R: def decorateur(fonc):\n    def wrapper(*args, **kwargs):\n        return fonc(*args, **kwargs)\n    return wrapper

Q: A quoi sert functools.wraps ?
R: functools.wraps preserve le nom et la docstring de la fonction originale quand on l'enveloppe dans un decorateur.

Q: Qu'est-ce qu'une closure en Python ?
R: Une closure est une fonction interne qui capture des variables de la portee englobante meme apres que cette portee soit terminee.

Q: Comment fonctionne *args ?
R: *args collecte les arguments positionnels supplementaires dans un tuple.

Q: Comment fonctionne **kwargs ?
R: **kwargs collecte les arguments nommes supplementaires dans un dictionnaire.

Q: Qu'est-ce qu'une fonction lambda ?
R: Une lambda est une fonction anonyme d'une seule expression, ecrite avec le mot-cle lambda.

Q: Quand utiliser une lambda plutot qu'une fonction def ?
R: Pour une petite fonction utilisee une seule fois, par exemple comme cle de tri.

Q: A quoi sert functools.reduce ?
R: reduce applique une fonction cumulative a une sequence pour la reduire a une seule valeur.

Q: A quoi sert functools.partial ?
R: partial fixe certains arguments d'une fonction pour creer une nouvelle fonction avec moins de parametres.

Q: A quoi sert functools.lru_cache ?
R: lru_cache met en cache les resultats d'une fonction pour eviter de recalculer les memes appels.

Q: Qu'est-ce qu'un generateur en Python ?
R: Un generateur est une fonction qui utilise yield pour produire une sequence de valeurs paresseusement, une a la fois.

Q: Quelle est la difference entre return et yield ?
R: return termine la fonction et renvoie une valeur, yield suspend la fonction et peut reprendre plus tard.

Q: A quoi sert yield from ?
R: yield from delegue l'iteration a un sous-generateur ou un iterable.

Q: Qu'est-ce qu'une expression generatrice ?
R: C'est une comprehension entre parentheses, comme (x*x for x in range(10)), qui produit les valeurs paresseusement.

Q: Quelle est la difference entre une liste et un generateur ?
R: Une liste garde toutes les valeurs en memoire, un generateur les produit une par une sans tout stocker.

Q: Qu'est-ce que le module itertools ?
R: itertools fournit des outils pour construire des iterateurs efficaces, comme chain, cycle, product et combinations.

Q: A quoi sert itertools.chain ?
R: chain enchaine plusieurs iterables en une seule sequence continue.

Q: A quoi sert itertools.count ?
R: count genere une sequence infinie de nombres a partir d'une valeur de depart.

Q: Comment definir une classe en Python ?
R: class NomClasse:\n    def __init__(self, valeur):\n        self.valeur = valeur

Q: Quelle est la difference entre une methode et une methode de classe ?
R: Une methode normale prend self, une methode de classe prend cls et est marquee @classmethod.

Q: A quoi sert @staticmethod ?
R: @staticmethod definit une methode qui n'a besoin ni de self ni de cls, comme une fonction rangee dans la classe.

Q: Qu'est-ce qu'une property en Python ?
R: Une property permet d'acceder a une methode comme si c'etait un attribut, via le decorateur @property.

Q: Comment definir un setter avec property ?
R: On definit une methode avec @property puis une autre avec @nom.setter pour permettre l'assignation.

Q: Qu'est-ce que __init__ ?
R: __init__ est la methode appelee automatiquement pour initialiser une nouvelle instance d'une classe.

Q: Qu'est-ce que __repr__ ?
R: __repr__ retourne une representation texte de l'objet, utile pour le debogage.

Q: Quelle est la difference entre __repr__ et __str__ ?
R: __repr__ vise les developpeurs et doit etre non ambigu, __str__ vise l'affichage lisible pour l'utilisateur.

Q: Qu'est-ce que __eq__ ?
R: __eq__ definit le comportement de l'operateur == pour les instances de la classe.

Q: Qu'est-ce que __len__ ?
R: __len__ permet a un objet de repondre a la fonction len().

Q: Qu'est-ce que __iter__ ?
R: __iter__ permet a un objet d'etre utilise dans une boucle for, en retournant un iterateur.

Q: Qu'est-ce qu'un context manager ?
R: Un context manager gere l'entree et la sortie d'un bloc with, via les methodes __enter__ et __exit__.

Q: Comment ecrire un context manager avec un decorateur ?
R: On utilise @contextlib.contextmanager sur une fonction generateur avec un seul yield.

Q: Qu'est-ce qu'une dataclass ?
R: Une dataclass est une classe generee avec @dataclass qui cree automatiquement __init__ et __repr__ a partir des attributs.

Q: Qu'est-ce que l'heritage multiple en Python ?
R: Une classe peut heriter de plusieurs classes parentes, Python resout l'ordre via le MRO, method resolution order.

Q: Qu'est-ce qu'une classe abstraite ?
R: Une classe abstraite, via le module abc, definit des methodes que les sous-classes doivent implementer.

Q: Comment gerer une exception en Python ?
R: try:\n    code()\nexcept Exception as e:\n    gerer(e)

Q: Quelle est l'utilite de finally ?
R: finally execute du code apres try et except, que l'exception ait eu lieu ou non.

Q: Quelle est l'utilite de else dans un try ?
R: else s'execute seulement si aucune exception n'a ete levee dans le bloc try.

Q: Comment definir une exception personnalisee ?
R: class MonErreur(Exception):\n    pass

Q: Qu'est-ce que raise ... from ... ?
R: raise ... from ... chaine une nouvelle exception a l'exception d'origine pour garder le contexte.

Q: Qu'est-ce que les annotations de type en Python ?
R: Les annotations de type indiquent le type attendu, comme def f(x: int) -> str, sans etre verifiees a l'execution.

Q: A quoi sert le module typing ?
R: typing fournit des types comme List, Dict, Optional et Union pour annoter du code plus precisement.

Q: Que signifie Optional[int] ?
R: Optional[int] signifie que la valeur peut etre un int ou None.

Q: Qu'est-ce qu'une comprehension de liste ?
R: [x*x for x in range(10)] construit une nouvelle liste en une seule expression.

Q: Qu'est-ce qu'une comprehension de dictionnaire ?
R: {k: v for k, v in paires} construit un dictionnaire en une seule expression.

Q: Qu'est-ce que l'operateur walrus ?
R: L'operateur := assigne une valeur a une variable a l'interieur d'une expression, par exemple dans une condition.

Q: Comment deballer une liste en Python ?
R: a, b, *reste = [1, 2, 3, 4] assigne a=1, b=2 et reste=[3, 4].

Q: Qu'est-ce que collections.Counter ?
R: Counter compte les occurrences des elements d'un iterable et retourne un dictionnaire de comptes.

Q: Qu'est-ce que collections.defaultdict ?
R: defaultdict cree automatiquement une valeur par defaut pour une cle absente au lieu de lever une erreur.

Q: Qu'est-ce que collections.namedtuple ?
R: namedtuple cree une classe legere de tuple avec des champs nommes accessibles par attribut.

Q: Qu'est-ce que collections.deque ?
R: deque est une file double, efficace pour ajouter ou retirer des elements aux deux extremites.

Q: Quelle est la difference entre une liste et un tuple ?
R: Une liste est modifiable, un tuple est immuable une fois cree.

Q: Pourquoi eviter les arguments par defaut mutables ?
R: Un argument par defaut mutable comme une liste est cree une seule fois et partage entre tous les appels, causant des bugs.

Q: Qu'est-ce que __slots__ ?
R: __slots__ limite les attributs possibles d'une classe et reduit la memoire utilisee par instance.

Q: Qu'est-ce que le GIL en Python ?
R: Le GIL, global interpreter lock, empeche plusieurs threads Python d'executer du bytecode en meme temps dans un seul processus.

Q: Quand utiliser multiprocessing plutot que threading ?
R: multiprocessing pour du calcul intensif CPU, threading pour des taches limitees par les entrees-sorties.

Q: Qu'est-ce que asyncio ?
R: asyncio permet d'ecrire du code asynchrone avec async et await pour gerer plusieurs taches concurrentes sans threads.

Q: Que fait le mot-cle async def ?
R: async def definit une coroutine, une fonction qui peut etre suspendue avec await.

Q: Que fait await ?
R: await suspend une coroutine jusqu'a ce que la tache attendue soit terminee.

Q: Quelle est la difference entre EAFP et LBYL ?
R: EAFP, easier to ask forgiveness than permission, essaie puis attrape l'erreur ; LBYL verifie les conditions avant d'agir.

R: with garantit que le fichier est ferme automatiquement, meme en cas d'erreur.
