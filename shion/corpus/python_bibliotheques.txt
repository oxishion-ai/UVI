Q: Qu'est-ce que NumPy ?
R: NumPy est une bibliotheque Python pour le calcul numerique, centree sur les tableaux multidimensionnels efficaces.

Q: Comment creer un tableau NumPy ?
R: import numpy as np\ntableau = np.array([1, 2, 3])

Q: Qu'est-ce qu'un tableau NumPy de zeros ?
R: np.zeros((3, 3)) cree un tableau trois par trois rempli de zeros.

Q: Comment multiplier deux tableaux NumPy ?
R: a * b multiplie element par element, tandis que a @ b effectue une multiplication matricielle.

Q: Qu'est-ce que Pandas ?

Q: Comment lire un fichier CSV avec Pandas ?

Q: Comment afficher les premieres lignes d'un DataFrame ?
R: df.head() affiche les cinq premieres lignes par defaut.

Q: Comment tracer un graphique simple avec Matplotlib ?

Q: Comment recuperer du JSON depuis une requete HTTP ?
